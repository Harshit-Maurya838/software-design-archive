# SOLID Principles

## What are the SOLID Principles?
SOLID is an acronym for five design principles intended to make software designs more understandable, flexible, and maintainable. Coined by Robert C. Martin (Uncle Bob), these principles form the bedrock of modern Object-Oriented Design and Agile software development.

If OOP concepts (Encapsulation, Polymorphism) are the tools, the SOLID principles are the blueprints for how to use those tools correctly.

## Why Learn SOLID?
In LLD (Low-Level Design) interviews, you are not just judged on whether your code works, but whether it can survive changing requirements.

If the interviewer says: "Now add a new payment method," or "Now we need to send SMS instead of Emails," they are testing if your design follows the Open-Closed Principle and Dependency Inversion Principle. Code that violates SOLID is rigid, fragile, and hard to test.
